# 全市场联动 UI 优化设计（Asset-Type Linked Navigation）

> 日期：2026-08-06
> 状态：grill 讨论定案（用户确认）
> 前置：Phase 5 全市场数据（87 只/8 类，market_funds.json/market_quarterly.json/完成度 149 行）+ 现有看板（4 Tab）

## 问题

侧边栏「市场筛选 → 资产类型」可选 8 类全市场，但「选择REIT」固定 14 只高速——筛选器与内容割裂（选了「能源」基金选择器仍是高速基金）。

## 目标

资产类型筛选 → 基金选择器联动：选「能源」→ 选择器列能源基金，选中后可查看其经营数据（季度表）、行情、估值对标。默认「高速」。

## 设计定案（不得随意更改）

| 模块 | 行为 |
|---|---|
| 联动核心 | `asset_type` selectbox（8 类，默认「高速」）→ 基金选择器 options = 该类型基金（market_funds.json 全市场 87 只，code+name） |
| 经营数据 Tab | 高速基金：现状（月度明细+季度明细+KPI）；**非高速基金：仅季度数据表**（Phase 5 现有字段：报告期/总收入/净利润/可供分配/EBITDA/NAV/出租率等有则显示），**不渲染月度区块**（无空态提示） |
| 状态墙 | 跟随 `asset_type`：色点带显示当前类型基金（完成度数据来自全市场完成度记录；无完成度 → 灰点） |
| 估值对标 | 现有 asset_type 筛选逻辑保留，与选择器联动一致 |
| 行情 Tab | 现有全市场行情逻辑（akshare 87 只）保持 |
| 明确不做 | 类型特有指标（发电量/利用小时/出租率趋势）、月度空态提示、数据导出 |

## 数据与降级（**高速零变化 + 如实提示**）

- **高速基金体验零变化（硬约束）**：asset_type=「高速」时——基金选择器、经营数据 Tab、状态墙、估值对标的渲染路径与数据源**与现状完全一致**，不因联动引入任何新提示/新文案/新元素（高速数据在模板 Excel，不依赖 market_funds）
- `market_funds.json` 缺失/损坏 → **如实提示**：`st.warning`「全市场基金数据缺失（文件不存在或损坏），当前仅可浏览高速基金」；**不静默回退、不假装正常**；非高速类型下基金选择器无可选项并显示该提示，高速类型照常
- 非高速类型无基金/无季度数据 → `st.info`「该资产类型暂无数据」
- 状态墙：无完成度数据的基金 → 灰点（现有 `_NO_RECORD_GRAY`）

## 测试策略

- AppTest：选「能源」（或任一非高速类型）→ 基金选择器 options 变化（含能源基金代码）；选中非高速基金 → 经营数据 Tab 渲染季度表、无「月度」相关区块/文案
- **market_funds.json 缺失（monkeypatch 路径）**：选非高速类型 → 出现 `st.warning`（含「全市场基金数据缺失」文案），**不是静默回退**；选「高速」→ 无 warning、14 只高速照常
- 非高速类型无数据 → `st.info` 降级
- 现有 4 Tab AppTest 不回归（406 基线）
