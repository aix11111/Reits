# 全市场联动 UI 设计（Asset-Type Linked Navigation）

> 日期：2026-08-06
> 状态：**最终定案**（用户确认表格版，重写于 2026-08-06 第二轮讨论）
> 前置：Phase 5 全市场数据（87 只/8 类，market_funds.json/market_quarterly.json/完成度 149 行）+ 现有看板（4 Tab）

## 问题

侧边栏「市场筛选 → 资产类型」可选 8 类全市场，但「选择REIT」固定 14 只高速——筛选器与内容割裂。

## 定案（用户确认，不得更改）

| 模块 | 改动 |
|---|---|
| **联动核心** | 资产类型筛选（8 类）→ 基金选择器列出该类基金（全市场 87 只可分）；**默认「高速」** |
| **经营数据 Tab** | 高速基金：**现状**（月度明细+季度）；非高速基金：**季度数据表**（Phase 5 字段：总收入/净利/可供分配/出租率等有则显示），**月度区块显示「该资产类型暂无月度披露」** |
| **状态墙** | **跟随筛选**：色点带显示当前资产类型基金（数据基础：全市场完成度 149 行已有；无记录灰点） |
| **估值对标** | 已支持资产类型筛选（现状），联动后选择器与之一致 |
| **行情 Tab** | 全市场行情已有（akshare 87 只），非高速基金可用 |
| **下一轮** | 类型特有指标（能源→发电量/利用小时，出租率趋势） |

## 数据与降级

- **高速零变化（硬约束）**：asset_type=「高速」时——基金选择器、经营数据 Tab、状态墙、估值对标渲染路径与数据源**与现状完全一致**（高速数据在模板 Excel，不依赖 market_funds；高速列表=静态 14 只，不从 market_funds 取）
- `market_funds.json` 缺失/损坏 → **如实提示**：`st.warning`「全市场基金数据缺失（文件不存在或损坏），当前仅可浏览高速基金」；**不静默回退**；非高速类型下选择器无可选项，高速类型照常
- 非高速类型无基金/无季度数据 → `st.info`「该资产类型暂无数据」

## 测试策略（TDD）

1. **联动**：选「能源」→ 选择器 options = 能源基金（含 180401 等），不含 180201；默认「高速」→ 14 只高速
2. **经营数据 Tab**：选中非高速基金 → 渲染季度数据表（报告期列存在）+ **月度区块显示「该资产类型暂无月度披露」文案**；选中高速基金 → 现状（月度+季度）不变
3. **market_funds.json 缺失**（monkeypatch）→ 选非高速类型：`st.warning` 含「全市场基金数据缺失」、选择器无可选项；选「高速」：无 warning、14 只照常
