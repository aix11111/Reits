# 全市场扩展设计（Phase 5: Full Market）

> 日期：2026-08-04 | 状态：已确认路线（用户 2026-08-04 拍板）
> 前置：Phase 1-4 全部交付（14 只高速资产 + 估值对标 + 增量管线）

## 目标

从 14 只高速公路 REITs 扩展到全市场 **86-93 只**（8 大资产类型：高速公路/产业园区/仓储物流/能源/生态环保/保障性租赁住房/消费基础设施/商业不动产），核心骨架 = 全市场季度核心财务数据层 + 估值对标覆盖全市场。

## 侦察结论（2026-08-04 已执行）

1. 全市场已上市 **86-93 只**（2026-08 口径：86 只上市 + 扩募后 87-93），首发规模 2,088 亿
2. **非高速季报与高速同构**（508000 张江产业园 2026Q2 实测）：
   - 3.1 主要财务指标：本期收入 30,650,710.62 / 本期净利润 -11,644,536.88 ✓（同定位）
   - 4.2.1 项目公司表：营业收入/营业成本/EBITDA ✓（同构）
   - **可供分配表**：「本报告期的可供分配金额」期间/金额/单位金额（本期 23,695,441.92 / 0.0247）✓ 同构（标题措辞「本报告期的」与高速「本报告期及近三年的」略异——匹配放宽）
   - 季报无期末基金份额净值 ✓（与高速一致，净值走年报）
   - 出租率类指标（4.1.3 期末出租率 88.12%/平均租金 5.44 元/平/天/收缴率 100%）结构清晰——Phase 5b 解析
3. 东财 akshare REITs 列表接口被拒（RemoteDisconnected）——全市场清单从交易所公告接口/静态核验获取

## 核心口径

| 指标 | 口径 | 说明 |
|---|---|---|
| 分派率收益率 | TTM 近 4 季可供分配 ÷ 市值（复用 Phase 4 valuation.py） | 全市场横向排名；<4 季标注「年化」 |
| NAV 折溢价 | 市价 ÷ 最新年报份额净值 − 1 | 年报 3.2 节，年度口径 |
| IRR | **仅有限期资产适用**（高速/能源/环保类） | 产权类（产业园/保租房/仓储/消费）标注「不适用（产权类）」 |
| 完成度 | 年报实际 vs 招募说明书预测（复用 parser_annual） | 全市场年度 |

## Phase 5a：全市场骨架（第一步）

1. **全市场清单**：`data/market_funds.json`（86+ 只：代码/名称/资产类型/上市日/交易所）——数据源：交易所 REITs 板块公告列表（sse/cninfo 接口复用）+ 人工核验清单（web 搜索 2-3 个来源交叉确认，不编造）；资产类型分类表（8 类）
2. **季度核心财务采集**：`tools/reits_collector/parser_quarterly.py` 扩展标题匹配（「本报告期的可供分配金额」变体）+ `fetch_market_quarterly()`（新增 update 管线函数，全市场逐基金拉季报 PDF → 解析 → `market_quarterly.json`；沪市限流 15s/基金 + 90s 重试；PDF 复用 `data/_cache/quarterly_market/`）
3. **市值快照扩展**：`update.py` 快照覆盖全市场（份额来源：各基金季报/发行数据——非高速基金份额需采集 `market_shares.json`）
4. **年报净值/完成度扩展**：parser_annual 全市场（3.2 净值 + 3.3.3 完成度）→ `market_completion.json`（年度增量）

## 错误处理与降级

- 清单核验：2+ 来源交叉确认；无法确认的基金不入库（宁缺毋滥）
- 单基金季度/年报失败 → errors 收集，不影响其余
- 类型特有指标缺失 → 该类型区块不显示（不显示「—」占位堆砌）
- IRR 对产权类标注「不适用」而非计算
- 沪市限流：沿用 15s 间隔 + 90s×3 重试

## 明确不做（YAGNI）

- 月度经营数据（高速特有车流量之外的类型月度披露）——多数类型无月度披露，不做
- 性价比评分（用户已取消）
- 数据导出/主动提醒（用户暂缓）
- 完成度预测模型（无招募说明书预测值的基金不做推断）
